- Previous version: 1.19.0
- New version: 1.20.0
- Version increment: minor release
- Deployment target: production
- Audit note: this release automatically archives tasks that have remained closed for two weeks while preserving a visible task-level audit trail.

## Release Contents

- Track the time of each task's latest status transition independently from ordinary edits.
- Run closed-task archival at application startup and daily thereafter.
- Archive active `Done` and `Won't Fix` tasks once they reach the 14-day threshold.
- Add an automatic audit-history entry with the archival timestamp and closed status.
- Restart the retention window when an archived closed task is restored.
- Allow the retention period and job interval to be configured through environment variables.
