- Audit note: this release adds an OAuth-free calendar import path through private iCalendar feeds.

## Release Contents

- Store each user's private iCalendar feed URL as authenticated AES-256-GCM ciphertext.
- Import upcoming one-time and recurring events into the existing meeting capture flow.
- Keep Google Calendar OAuth import available and allow users with both connectors to choose the source.
- Block private-network targets and IPv4-mapped bypasses, validate redirects, cap downloads, and avoid returning saved feed URLs to the browser.
